# 📊 Gestão de Hábitos

Este projeto foi desenvolvido como parte do meu processo de aprendizado em programação, com foco na construção de um sistema completo para gerenciamento de hábitos.

A aplicação permite o cadastro de usuários, criação de hábitos e registro diário de progresso, incluindo acompanhamento de sequência (streak) e consultas no banco de dados.

---

## 🎯 Objetivo

O principal objetivo deste projeto é praticar e consolidar conhecimentos em:

* Programação Orientada a Objetos (POO)
* Modularização de código
* Integração com banco de dados (SQLite)
* Escrita e otimização de consultas SQL
* Organização de um sistema real em múltiplos arquivos

Além disso, este projeto também serve como um registro da minha evolução como desenvolvedor, refletindo meu aprendizado ao longo do tempo.

---

## ⚙️ Funcionalidades

* Cadastro de usuários
* Criação e gerenciamento de hábitos
* Registro diário de atividades
* Cálculo de sequência (streak)
* Consultas personalizadas no banco de dados
* Menu interativo via terminal (CLI)

---

## 🛠️ Tecnologias utilizadas

* Python
* SQLite
